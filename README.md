# VACCOVID - Coronavirus Vaccine and Treatment Tracker

> 🏆 **Arman Feili's 1st Project** | Originally live from 2020-2023 | Now preserved as a static showcase

## About

VACCOVID was a comprehensive COVID-19 tracking platform that provided real-time data on the coronavirus pandemic, vaccines, and treatments worldwide. This repository now serves as a **static archive** demonstrating how the application looked and functioned during the pandemic years (2020-2023).

## Features

### COVID-19 Data
- **Global Coverage**: Real-time statistics for all countries worldwide
- **State/Province Data**: Detailed breakdown for ~20 countries with regional data
- **Visualization**: Interactive tables, charts, and maps

### Vaccine & Treatment Tracker
- Complete list of all COVID-19 vaccines and treatments
- Development stages and clinical trial information
- Detailed information for each vaccine/treatment

### News Aggregation
- COVID-19, vaccine, and health news
- Aggregated from **23 broadcasting services**
- Real-time updates during active operation

## Tech Stack

- **Frontend**: React.js with Redux
- **Backend**: Node.js with Express
- **Database**: PostgreSQL with TypeORM
- **Deployment**: Docker, Kubernetes, Helm

## Current Status

This project is now **archived as a static site** to preserve its historical significance during the COVID-19 pandemic. It demonstrates the original functionality and design from 2020-2023.
